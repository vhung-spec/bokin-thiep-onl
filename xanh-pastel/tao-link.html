1Nhạc nền

Hoặc tải file nhạc của bạn lên

Lấy mã GitHub thế nào?
  1. Đăng nhập GitHub, mở trang tạo mã (Fine-grained token).
  2. Đặt tên, ví dụ Nhạc thiệp cưới; Expiration chọn 30 ngày.
  3. Repository access → Only select repositories → chọn bokin-thiep-onl.
  4. Mục Permissions: bấm + Add permissions → chọn Contents → đổi quyền thành Read and write (dòng Metadata: Read-only tự thêm thì để nguyên). Giao diện cũ: Repository permissions → Contents → Read and write.
  5. Bấm Generate token, chép mã (bắt đầu bằng github_pat_) và dán vào ô trên.

Mã chỉ dùng để gửi file nhạc lên GitHub từ trình duyệt này, không gửi đi nơi khác. Đừng đưa mã cho người khác.

Nhạc đã tải lên

Nên dùng nhạc bạn có quyền sử dụng. File tối đa 20 MB.
