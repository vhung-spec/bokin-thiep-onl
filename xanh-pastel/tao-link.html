Lấy mã GitHub thế nào?
  1. Đăng nhập GitHub, mở trang tạo mã (Fine-grained token).
  2. Đặt tên, ví dụ Nhạc thiệp cưới; Expiration chọn 30 ngày.
  3. Repository access → Only select repositories → chọn bokin-thiep-onl.
  4. Mục Permissions: bấm + Add permissions → chọn Contents → đổi quyền thành Read and write (dòng Metadata: Read-only tự thêm thì để nguyên). Giao diện cũ: Repository permissions → Contents → Read and write.
  5. Bấm Generate token, chép mã (bắt đầu bằng github_pat_) và dán vào ô trên.

Mã chỉ dùng để gửi file nhạc lên GitHub từ trình duyệt này, không gửi đi nơi khác. Đừng đưa mã cho người khác.

Nên dùng nhạc bạn có quyền sử dụng. File tối đa 20 MB.

Lưu danh sách lên Google Sheet

Nhập mật khẩu xem thống kê để lưu danh sách khách lên Google Sheet: không lo mất, và cô dâu chú rể dùng chung một danh sách trên nhiều máy.

  1. Bấm , mở dự án Apps Script của thiệp, xoá hết mã cũ và dán mã mới vào.
  2. Gõ lại mật khẩu vào dòng var MAT_KHAU = '' (giữa hai dấu nháy), bấm Lưu.
  3. Triển khai → Quản lý các bản triển khai → bấm bút chì (Chỉnh sửa) → Phiên bản: Phiên bản mới → Triển khai. Link /exec giữ nguyên.
  4. Quay lại đây bấm Đồng bộ ngay.

Link ngắn có tên khách

Gửi qua Facebook, Zalo sẽ hiện “Thân gửi [tên khách] 💌” và link gọn dạng …/m/ab12cd. Mỗi khách một trang nhỏ trên GitHub (cần mã GitHub như khi tải nhạc). Lưu ý: tên khách nằm trong các trang này, ai xem repo trên GitHub cũng thấy.

Cách lấy mã: xem “Lấy mã GitHub thế nào?” ở mục 1. Nhạc nền (Contents: Read and write cho repo bokin-thiep-onl).
